# 🐍 Python Fundamentals: A Structured Learning Path

This repository serves as a **portfolio of initial Python scripts** and a comprehensive coding journal.

The project directly follows the curriculum and exercise progression from the renowned **Python 3 course by Professor Gustavo Guanabara (Curso em Vídeo)**, focusing on building skills from the absolute basics (Hello, World!) up to fundamental control structures.

My core objective is to document the learning process, reinforce concepts through practice, and demonstrate foundational competency in writing executable Python code.

---

## 🎯 Core Concepts Covered

This repository covers the essential foundational topics, typically aligned with "Mundo 1" and the start of "Mundo 2" of the course:

* **Syntax and Setup:** First scripts and fundamental language structure.
* **Variables & Data Types:** Working with standard types (`int`, `float`, `str`, `bool`).
* **Simple Data Structures:** Introduction to `lists` and `tuples`.
* **Operators:** Arithmetic, assignment, and logical comparison.
* **Flow Control (Conditions):** Implementing `if`, `elif`, and `else` statements.
* **Iteration (Loops):** Implementing `for` and `while` loops for task repetition.

---

## 📂 Repository Organization and Progression

The files are numerically ordered (`ex001.py`, `ex002.py`, etc.) to match the sequential progression of the course's classes and exercises. This structure validates a diligent, step-by-step approach to learning.
